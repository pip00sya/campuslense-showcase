# CampusLense: media and version provenance

The project gallery is retained from the QwertyS source and the original Eye172
case study. These are real hackathon-product interfaces and university/map
imagery, not generated mockups of an unimplemented product.

## Named QwertyS package

- `media/CampusLense_QwertyS_demo.mp4`: the source's
  `docs/hackathon/submission-package/CampusLense_QwertyS_demo.mp4`, exactly 180 seconds.
- `media/CampusLense_QwertyS_presentation.pdf`: the package PDF, also identical
  to `docs/pitch/CampusLense_QwertyS_2026_v2.pdf`.
- The PPTX is the corresponding `CampusLense_QwertyS_2026_v2.pptx`.
- `media/demo-preview.jpg`: a frame at 35 seconds from that recording.
- `media/pitch-preview.jpg`: an unchanged render of the PDF's first page.

The package was retained in the 11 October migration commit. The archive alone
does not establish that these exact binaries were the September jury submission.
The root README identifies the package without inventing such a timestamp.

## Earlier media and complete gallery

`media/campuslense-demo.mp4` is the earlier 133.72-second recording.
`media/CampusLens.pdf` is the early eight-slide draft, whose cover still has an
unfilled team label. Both remain as archive material; the named QwertyS package
is the primary presentation.

`media/gallery/` preserves all 28 original `docs/screens/` images. The root
gallery selection and [GALLERY.md](GALLERY.md) organize the views for review.
`materials/LOCUS-Case-01.pdf` and `materials/LOCUS-Regulations-v2.pdf` are organizer
documents, retained with their attribution. `media/locus-winners.jpg` comes from
the organizer's result announcement, linked in [HACKATHON.md](HACKATHON.md).

University photographs, maps and panoramas retain their respective rights and
attributions. This portfolio does not relicense those assets. Internal accuracy
and speed figures are described as team-reported development measurements.
The planned user pilot is not shown as completed or measured adoption.
