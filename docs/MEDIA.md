# Media provenance

This showcase preserves the project-specific gallery from
[Eye172/campuslense-showcase](https://github.com/Eye172/campuslense-showcase) and adds the retained project media
identified below. Screenshots show real application interfaces; synthetic demo records,
archived runs and interface generations are identified in the README captions.

QwertyS: Nurkhan Aimukatov and Shakhnazar Akhmer. Existing presentation authorship is
credited to the shared project and the original Eye172 showcase. This new repository
has its own publication history and does not use its commit count to attribute the
original engineering work.

Application licenses and third-party media rights are governed by their respective
source projects; this presentation repository does not relicense the application code
or third-party university photographs. The LOCUS case/regulations, where included,
are organizer documents retained with their original attribution.

[File hashes and sizes](media-manifest.json) identify the included media. No certificate
image or award graphic has been invented. Certificates held by the team are mentioned
only in the event record until their actual scans are supplied.

`media/campuslense-demo.mp4` and `media/CampusLens.pdf` are the retained hackathon recording and pitch. The original LOCUS case and regulations are retained in `materials/`.

`media/locus-winners.jpg` is the unchanged original final-results artwork from LOCUS / @locus_ed, published 1 October 2026: https://www.instagram.com/locus_ed/p/Dd8uIpDtT4z/ . It was retrieved through the rendered public post on 12 October 2026. The separately named CampusLens special-award team in that post is distinct from CampusLense (QwertyS), the winning project documented here.
